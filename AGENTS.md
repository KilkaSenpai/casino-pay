# Agents

This project is portable: clone the repo and the same agent context is available under `.agents/`.

## Start here

1. `.agents/README.md` — index of context, prompts, and skills
2. `.agents/context/project.md` — stack, env, and source map
3. `.agents/prompts/system.md` — default system prompt and coding rules
4. `.cursorrules` — Cursor-specific copy of those rules

## Payload CMS

Use the Payload CMS skill at `.agents/skills/payload/`.

Start with `.agents/skills/payload/SKILL.md`, then see `.agents/skills/payload/reference/` for fields, hooks, access control, queries, and adapters.
